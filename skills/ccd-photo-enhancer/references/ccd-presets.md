# CCD 预设与强度模型

本目录把早期便携数码相机的观感拆为三个正交描述轴。轴用于解释配方和扩展预设；当前 L2 脚本提供四个离散点，并不声称对真实相机作物理建模。

## 三个轴

1. **闪光观感**：`none` 或 `direct-tonal`。`direct-tonal` 只通过曝光、反差、高光和色彩曲线近似直闪的强烈数码观感；没有人像分割、光源重建或阴影合成，不能声称生成真实机顶闪光和投影阴影。
2. **环境光倾向**：`daylight`、`indoor`、`night`。这是色彩/曲线调校方向，不从图像中自动推断拍摄时间。选择与原片冲突时，跟随原图实际光线和用户说明，不把白天强行变成夜景。
3. **退化量**：`clean` 或 `light-aged`。控制高光曲线、暗角及颗粒；非闪光 aged 配方可压缩高光，直闪配方则先抬升高光，再经软肩滚降。只有输入中原本近白的高光点会硬剪切；不应把中亮灰整片染成纯白。暗角在像素乘法上限为 20%（显示测量会有 8-bit 量化误差），且纯黑/近黑像素受保护；常见夜景背景仍应可见边缘衰减。默认不加日期戳、重漏光、严重模糊、强色差或大面积刮痕。

## L2 预设

| ID | 轴位置 | 默认表现 | 适用场景 |
|---|---|---|---|
| `daylight-clean` | 无闪光 / 日光 / 干净 | 轻微数码饱和、直接反差和清晰感；几乎不加颗粒 | 日间人像、街景、旅行照；希望复古但不明显做旧 |
| `daylight-aged` | 无闪光 / 日光 / 轻退化 | 日光直出色彩、较明显的高光压缩和少量颗粒/暗角 | 用户说“旧数码”“轻微做旧” |
| `indoor-flash` | 直闪观感 / 室内 / 干净 | 更明显的反差和高端提亮/剪切；低强度颗粒；不创造真实闪光阴影 | 室内派对、近距离随手拍 |
| `night-flash` | 直闪观感 / 夜景 / 轻退化 | 偏冷暗部、明显高端剪切、可辨认颗粒与更强暗角；暗部保护以免一味压黑，不抬亮全背景伪造光源 | 原片本身为夜景、用户想要夜拍卡片机观感 |

“室内闪光”和“夜景闪光”的差异由环境倾向/退化轴体现，而不是两个不透明滤镜。当前 L2 只实现上述四个离散配方，三轴用于解释和未来扩展，**尚不支持任意轴组合或插值**。若用户要求白天闪光、室内无闪光等组合，不能只改标签或选错环境的预设后声称精确匹配；应说明当前本地配方限制，转到获授权的 L1 场景编辑，或提供 L3 提示词。

## 强度语义

主强度为 `0–100`，默认 `50`：

- `0`：关闭风格曲线/颗粒/暗角等默认效果；仍会应用 EXIF 方向校正与需要的色彩管理，并写出新文件。JPEG 仍会重新编码，可能产生有损差异；PNG 在无色彩转换时保持像素值，但不会保留 EXIF/GPS。
- `1–29`：轻微风格提示。
- `30–69`：中等、可辨认但不夸张。默认 `50` 时四个预设彼此差异**刻意做得细微**（在自带校准图与照片型固件上，两两平均差约 1.6–1.8/255）。
- `70–100`：强风格；预设性格明显（同固件上强度 80 时两两平均差 ≥2.4/255）。若用户要求一眼看出“室内直闪”与“日光做旧”的区别，用 70–90。强度越高越容易出现高光/阴影截断或颜色过饱和，完成后检查剪切比例。

每个子效果默认**跟随主强度**。可单独覆盖 `--grain-strength`、`--color-strength`、`--vignette-strength`、`--sharpness-strength`，其值为 0–100 的**配方系数占比**，不是跨预设统一的物理强度单位：`100` 表示用满该预设中这个效果的系数，`0` 表示关闭该子效果。由于不同预设的颗粒/暗角上限系数不同，同一个覆盖数值在不同预设下不会产生相同的绝对强度。例：主强度 70、颗粒覆盖 10，表示整体风格较强但只用该配方颗粒上限的 10%。不要把每个覆盖参数都作为交互必问项。

## 参考命令

```text
python scripts/apply_ccd.py input.jpg --preset daylight-aged --strength 50 --seed 0
python scripts/apply_ccd.py input.png --preset indoor-flash --strength 65 --grain-strength 10 --seed 17 --out result.png
```

没有显式 `--out` 时脚本在输入旁创建唯一新文件；透明图或 PNG 输入默认 PNG，其他静态照片默认 JPEG。若要选择子效果覆盖，先确认用户表达的偏好；不要仅因强度大就自动加日期戳或漏光。

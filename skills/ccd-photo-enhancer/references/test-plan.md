# 验收与回归计划

本 skill 的回归测试关注“路由正确、像素处理可复现、原图安全”，不以主观滤镜评分冒充客观正确性。

## 自动化测试（`python -m unittest discover -s tests`）

`tests/test_apply_ccd.py` 使用程序生成的临时图像，不依赖用户照片；优先在 `tests/.test-work` 或 `CCD_TEST_TMP` 下使用 `os.makedirs` 创建唯一子目录。若目标不可写，会回退到 `LOCALAPPDATA`、`TEMP`、`TMP` 并在测试输出打印实际目录；不依赖系统 `tempfile` 私有 ACL。当前自动化覆盖：

- EXIF Orientation 3/5/6/8 的显示方向与尺寸；EXIF 不复制；宽高比报告正确。
- PNG 在强度 0 且无需色彩转换时像素中性；同一输入/参数/seed 可复现，不同颗粒 seed 可改变结果。
- RGBA 和调色板透明度保持；透明源显式输出 JPEG 时拒绝；不支持的动画/浮点/HEIC 输入明确失败。
- 高熵 JPEG 输入（600×400、1200×800）经 JPEG 输出可重新解码；另测 JPEG quality 范围/报告值与 WebP 输出。
- `--preview` 返回指标与 `output_path: null`，不创建文件；与 `--out` 同用时明确拒绝。默认输出不覆盖输入；已存在目标自动加序号；同路径、缺失输出目录和越界参数拒绝。
- 批处理只处理目录第一层，强制独立且已存在的输出目录；源文件与既有输出不覆盖，重复运行生成新序号。验证非照片文件计数、HEIC 逐张失败、部分成功退出码 1、全部失败退出码 2，以及单张默认强度 50 的兼容契约。
- 无 ICC CMYK 显示警告；损坏 ICC 安全失败；16-bit 整数灰度量化有报告；像素上限可由 `--max-pixels` 向下设定。
- 关闭颗粒后，强度 80 的四预设任意两两平均像素差：硬边校准图与照片型固件（天空/地面/主体/高光）都 ≥3.4/255；默认强度 50 实测约 2.2–2.3/255。
- 205 中亮灰加 1% 原始近白高光的直闪固件在强度 50/100 时近白与通道剪切比例都 ≤5%，中亮灰不整片变纯白；150–255 亮度梯度单调、输出码数 ≥60，最长同值段在强度 50 时 ≤6 级、100 时 ≤10 级（早期版本曾出现 ≥27 级平台）；人像色块默认 50 的红向位移 ≤18 且红-绿偏移 ≤10（单一合成色块，不是肤色检测器）。
- aged 满强度中灰暗角可测（8–30%）；室内/夜闪的灰阶 18 暗背景在强度 50/100 的角落衰减须为 5–45%，避免暗场完全看不到暗角或整片压黑；45% 是像素乘法上限，8-bit 极暗值的相对读数需考虑量化。
- 新增效果分别验证：辉光具有暖色与局部性，跨 256 行分块的结果与整图连续双线性放大一致；黑位压深中间调且保持白场与单调性；闪光中心提亮不使饱和红色通道新增剪切，边缘仍相对压暗。

每条自动化测试只证明相应合成固件/参数的事实，不证明真实照片中的人物身份、构图或主观“像 CCD”。JPEG 输出在强度 0 仍会重编码，不能要求逐像素无损。

## 真实照片离线评测

`tests/real_photo_eval.py` 读取 `tests/real-photo-manifest.json`，把来源图统一缩放到长边 1600 像素作为评测固件，再通过实际 CLI 以 seed 7 运行默认与推荐强度。当前矩阵包含 15 张 Pexels 许可照片、30 次运行，覆盖低调/高调和多人像、室内活动、窗边逆光、日光风景、霓虹与雨夜反光。来源路径、页面、已有摄影者信息和许可均在 manifest 中记录；评测脚本本身不联网。

产物包括逐张前后对比、`docs/samples/real-evaluation-overview.jpg` 和 `docs/samples/real-evaluation.json`。报告记录来源 SHA-256、精确参数、依赖版本、近白/通道剪切/近黑、中心与角落亮度和平均像素差。当前平均变化约 11.1/255，最大处理后近白比例约 0.12%；低调人像的近黑比例从 8.99% 增至 12.30%，作为阴影风险案例保留。上述指标不替代逐张目视检查或真实 CCD 盲测。

## 手工 / 操作流程回归

1. **日间肖像**：选择 `daylight-clean`；查身份、肤色自然度、发丝/文字细节和高光剪切。
2. **室内近景**：选择 `indoor-flash`；检查直闪色调是否明显但不发明阴影/光斑。
3. **原片已有夜景**：选择 `night-flash`；检查暗部颗粒是否过重、背景是否被不合理提亮。
4. **只说“复古一点”**：默认 CCD 中档，不追问无关参数；显示 L2 状态和准确文件路径。
5. **明确要求水墨画**：不得调用 CCD 像素脚本；有获授权的图像编辑工具才走 L1，否则 L3 明确未处理并给提示词。
6. **明确胶片/胶卷**：不能默认为 CCD；转入胶片风格子路线或澄清。
7. **截图/已有滤镜图/HEIC**：不默认套 CCD；解释不适用、叠加风险或格式限制，并提供安全回退。
8. **后端不存在或本地脚本失败**：输出契约明确为“未处理”，能力层级 L3/错误层，输出文件“无”；不伪称成功。
9. **整组照片批处理**：先用代表照片在 50/75 强度间确认风格，再使用独立输出目录；检查成功/失败计数、输出路径、重复运行不覆盖和部分失败不被描述成整组完成。

## 通过标准

- 每条路径都标注实际使用的 L1/L2/L3；任何未调用的能力不能写成已使用。
- L2 对静态图片不做几何重定位或语义编辑，保持显示尺寸；允许色彩曲线、空间变化暗角和卷积锐化改变像素内容，输出必须与源是不同文件。
- 元数据默认不泄露；错误退出不留半成品。
- CCD 风格辨识度由人并排评估：“是否一眼像早期便携数码相机直出，而非普通饱和/棕褐滤镜？”测量指标只提供高光、阴影等技术警报。

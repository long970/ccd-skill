# 水墨画与其他媒介转换（L1/L3）

水墨画、油画、素描等是对媒介/纹理的转换，不是 CCD 像素滤镜。L2 脚本不实现这些风格；不得用“只加一点颗粒/灰度”冒充水墨画。

## 路由

- 用户明确要求“水墨画 / 国画 / 工笔”等：优先使用当前环境中已明确可调用、且获授权的生成式图像编辑工具（L1）。若没有，提供提示词（L3），并明确图片没有实际修改。
- 用户只说“风格化”，不要默认水墨画；沿用 CCD 默认或仅在选择会显著改变媒介时询问一次。
- 纯黑白钢笔线稿、泼墨写意、工笔设色等差异明显；用户没指定时选与其描述和原图相称的一种，并在交付说明中注明，不混合成含糊的“国风”。

## L1 编辑提示的构造

用动作指令开头，说明“编辑这张照片”，然后依次包含：

1. **只改的属性**：照片媒介转为哪种水墨表现（如淡墨晕染、干湿笔触、宣纸纹理、留白、有限设色）。不要使用空泛质量词代替具体语言。
2. **必须保留**：同一人物/人数、身份辨识特征、姿态、衣物/关键道具、主体左右位置、背景主要空间关系与原有可读文字；保持源图画幅和主体完整。
3. **风格边界**：只在用户要求时添加印章、题字、边框或新物件；无要求时不加。文本必须来自用户给定的精确字句，不自行编写日期、地点或题款。
4. **编辑强度**：让水墨媒介清晰可见，但不要为增强笔触而改写人物身份或重构场景。风格强度与内容保持是两项独立约束。

可用提示词骨架：

```text
请将这张照片编辑为【用户指定的水墨风格】作品。只转换绘画媒介与墨色表现：呈现【具体笔触、墨色层次、纸面质感、留白/设色】。保持照片中的同一人物、人数、姿势、衣着和关键道具；保留主体相对位置、主要背景空间关系、原始画幅与所有重要可读内容。不要新增题字、印章、日期、人物或道具。输出一张完整画面，不做前后对照拼图。
```

提示词中的保真条款是要求，不是保证。生成后仍需逐项核对；发现身份/构图漂移时，说明并尝试受控修订，不要称“完全保留”除非有证据。

## L3 回退

没有图像编辑后端时，只输出可复制的提示词和一行状态契约：

```text
处理状态：未处理
能力层级：L3 仅提示词
输出文件：无
```

提示词应针对“编辑现有照片”而不是重生成；不得把没有输出文件描述成已转换图片。
